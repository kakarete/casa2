# Casa 2 — Remodelação · modelo 3D

Modelo 3D interativo da remodelação da moradia R/C + 1 n.º 13 (estado atual com patologias e proposta).

Abrir `casa2_3d.html` no browser (precisa de internet: three.js vem do CDN jsDelivr).
Parâmetros no endereço (#): `estado=atual|proposta`, `vista=exterior|aerea|planta0|planta1|sala|cozinha|wc|garagem|q1|q2`, `modo=maquete`, `patologias=0`, `ao=0`.
Gerado a partir do motor da Casa 1; geometria de `_fontes/build_desenhos_casa2.py`, orçamento de `Orcamento/_fontes/cliente_dados.json`.

Ver online: https://kakarete.github.io/casa2/
